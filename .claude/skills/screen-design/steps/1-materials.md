# ステップ 1 / 6: 材料をそろえる

**なぜやる。** 画面に載せるものを決めないと、あとで「この機能も要る?」が何度も戻ってくる。先に、概念の単位で範囲を決める。
**できあがるもの。** `screens.yaml` の `concepts`(入れる概念)、`shared`(中心の概念)、`excluded`(入れない・未決の概念と理由)。
**目安。** 30 分。

## やること
1. `concepts.yaml` の概念を、1 つずつ見る。AI は、概念の目的を 1 文で読み上げ、「この版(P1)に入れるか」を聞く。
2. 答えを 3 つに分ける: **入れる**(`concepts`)、**入れない**(`excluded`、理由つき)、**未決**(`excluded`、`OQ-n` つき)。
3. 入れる概念のうち、**ほとんどの機能が使う中心の概念**を `shared` にする(例: 場所)。中心の概念は、1 つの画面に閉じず、必要な画面に出す。
4. 入れる概念の**アクション**を眺め、「誰が呼ぶか」(来場者か、運営か)を確かめる。呼ぶ人が違うアクションは、画面を分けたくなる印。
5. ジャーニー(`journey/*.md`)があれば、始点と終点を 1 行ずつ `screens.yaml` の `journeys` の下書きに写す。

## 評価基準(次に進む条件)
- [ ] 概念が、すべて「入れる / 入れない / 未決」のどれかに入っている(漏れなし)
- [ ] 入れない・未決の概念に、理由か `OQ-n` がある
- [ ] `shared` の概念が、`concepts` に入っている
- [ ] 入れる概念の、呼ぶ人が分かっている
