# ステップ 3 / 6: 分け方を選ぶ

**なぜやる。** ステップ 2 の評価から、画面のグループ分けの候補が、機械で出る。人は、それを見て選ぶだけ。ここで、画面の数と中身の大枠が決まる。
**できあがるもの。** `screens.yaml` の `screens`(画面の id、タイトル、本拠の概念、出る共有の概念)と、選んだ理由。
**目安。** 30 分。

## やること
1. `python3 tools/screen_groups.py groups.yaml --top 5` を実行する。AI は、候補を平易に説明する(「案 1 は 2 つの画面、〇〇と△△が同じ画面」)。
2. 各案の**良い点と、諦めた点**(一緒にできなかった prefer)を、1 行ずつ言う。
3. 候補が気に入らないときは、**相性を直して再実行**する(結果を無理に選ばない)。
4. 1 つ選ぶ。選んだ理由を `decisions.yaml` に 1 件残す(捨てた案と理由も)。
5. 画面ごとに、id(英数字)と、利用者の言葉のタイトルを付ける。

## 評価基準
- [ ] 選んだ分け方が、ツールの候補の 1 つ(must と apart を破っていない)
- [ ] 1 画面の概念数が、上限(`limits.max_concepts_per_screen`)以内
- [ ] 選んだ理由と、捨てた案が `decisions.yaml` にある
- [ ] 画面に、利用者の言葉のタイトルが付いている(技術の語を使わない)
